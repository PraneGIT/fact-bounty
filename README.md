# **FactBounty**

## **Overview**

FactBounty is a crowdsourced fact-checking platform designed to enhance the security, privacy, and trustworthiness of social media ecosystems. Leveraging AI-powered analytics and an intuitive UI, it enables users to verify the authenticity of content efficiently.

## **Getting Started**

### **Prerequisites**

- Go (>=1.21)
- Node.js (>=18.x)
- Docker & Docker Compose

### **Installation**

**Clone the repository**

```sh
git clone https://github.com/your-repo/fact-bounty.git
cd fact-bounty
```
